# PPAI APK

File instalasi Android untuk aplikasi **PPAI**, dashboard santri dan ustadz PP. Anwarul Islam.

## Unduh

| Versi | Untuk siapa | Unduh |
|-------|-------------|-------|
| Biasa | Sebagian besar HP, fitur lengkap | [none.apk](https://srv1-ppaix.vercel.app/app/none.apk) |
| Lite | HP dengan ruang atau memori terbatas | [lite.apk](https://srv1-ppaix.vercel.app/app/lite.apk) |

Versi terbaru juga tersedia di halaman [Releases](../../releases).

## Fitur

- Al-Qur'an
- Jadwal shalat
- Majmu'at (Qasidah Burdah, Istighosah, Hizib Nashor) dengan teks Arab, latin, dan terjemah
- Kitab pesantren
- Saldo dan riwayat transaksi
- PIN 6 digit untuk konfirmasi penarikan saldo
- Akun saya: ubah nama, kelola PIN, ganti password
- Untuk ustadz: kelola blog, galeri, pendaftaran, akun, dan saldo

## Cara pasang

1. Unduh file APK dari tabel di atas.
2. Buka file yang sudah diunduh.
3. Jika diminta, izinkan pemasangan dari sumber ini di pengaturan HP.
4. Ketuk Pasang, lalu buka aplikasi dan masuk dengan akun pesantren.

## Perbarui aplikasi

Unduh APK terbaru dan pasang di atas aplikasi lama. Data akun tetap aman karena tersimpan di server.

## Masalah umum

- **Pemasangan diblokir:** buka Pengaturan, cari "Pasang aplikasi tidak dikenal", lalu izinkan untuk browser atau pengelola file yang dipakai.
- **Aplikasi tidak bisa dipasang:** coba versi lite.
- **Lupa PIN atau password:** hubungi ustadz atau admin pesantren.

## Peran akun

| Peran | Akses |
|-------|-------|
| Santri | Baca Al-Qur'an, jadwal shalat, saldo dan riwayat, kelola akun dan PIN |
| Ustadz | Semua fitur santri, ditambah kelola blog, galeri, pendaftaran, akun, dan saldo |
| Developer | Semua fitur ustadz, ditambah daftar akun, file manager, dan editor database |
